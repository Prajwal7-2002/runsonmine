# RunsOnMine ⚡ Empirical Silicon Benchmark Studio

Interactive consumer GPU LLM serving benchmarks and crowdsourced empirical measurements on physical hardware.

* **Interactive Features:** 24 physical measurements on Dual Tesla T4 & RTX 3050 Laptop, concurrency scaling curves ($c=1 \to 8$), and 1-click PR submission portal.
* **GitHub Repository:** [Prajwal7-2002/runsonmine](https://github.com/Prajwal7-2002/runsonmine)
* **Dataset:** [prajwalpujari16/consumer-silicon-benchmarks](https://huggingface.co/datasets/prajwalpujari16/consumer-silicon-benchmarks)
* **Author:** Prajwal Pujari ([@Prajwal7-2002](https://github.com/Prajwal7-2002))
